# РЕФЕРАТ ПРОГРАММЫ ДЛЯ ЭВМ (ДЛЯ ПОДАЧИ В ФИПС / РОСПАТЕНТ)

**Название программы для ЭВМ:**
Программный комплекс пространственного клеточного вычисления и управления трёхмерной матрицей связанных узлов «БОЛЬШОЙ КУБ-125 СТЕРЖЕНЬ» (Среда исполнения ЛЕКСИКОН)

**Правообладатель и Автор:**
Чиркин Дмитрий Николаевич (дата рождения: 14.03.1980), гражданин Российской Федерации.

**Аннотация (назначение, область применения и функциональные возможности):**
Программа предназначена для проектирования, визуализации на 3D-мнемосхеме, потактового моделирования и исполнения распределённых алгоритмов управления и цифровой обработки сигналов в трёхмерной топологии из 125 взаимосвязанных вычислительных узлов (матрица 5×5×5 малых КУБов, сопряжённых через 750 функциональных граней и 300 внутренних межгранных мостов).
Каждый узел матрицы обладает шестью программируемыми гранями (`01_ВХОД`, `02_ПАМЯТЬ`, `03_ЛОГИКА`, `04_СВЯЗЬ`, `05_КОНТРОЛЬ`, `06_ВЫХОД`) и исполняет детерминированный по тактам предметно-ориентированный код на русском языке (ЛЕКСИКОН).
Комплекс обеспечивает:
1. Индивидуальное и групповое программирование логики каждого из 125 узлов на русском языке с ограничением тактового бюджета.
2. Синхронную и волновую маршрутизацию потоков данных между сопряжёнными гранями соседних узлов по осям X, Y, Z в режиме реального времени (частоты тактирования 1 Гц и 10 Гц).
3. Энергонезависимое хранение состояния матрицы и формирование криптографически верифицируемых слепков конфигурации (`.kub`) с контрольной суммой FNV-1a.
4. Обмен телеметрией и управляющими воздействиями с внешними промышленными серверами и контроллерами по протоколам WebSocket / HTTP через граничные слои матрицы.

**Язык программирования:** Java, JavaScript (ES6), HTML5, предметно-ориентированный язык ЛЕКСИКОН.
**Объём программы:** 48 КБ (исходный текст), 2.1 МБ (исполняемый пакет APK).
**Операционная система:** Android 7.0 и выше (API 24+), Linux / кроссплатформенная среда.
